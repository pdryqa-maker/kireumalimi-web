# 로그인 전 위치 고르기와 개인정보 처리방침 (짧은 설계)

## 왜
로그인하지 않은 사람에게 울주군(시연 지역)이 기본으로 깔려, 다른 지역 사람에게는 엉뚱한 출발 위치·지역 평균이 보인다.
이용자의 말: "로그인을 안 했을 때 기본으로 울주군이 뜨던데 … 그냥 위치를 선택할 수 있도록."
또 사진·질문이 해외 AI(Anthropic)로 가고 위치를 받으므로 개인정보 처리방침이 필요하다.

## 정한 것(이용자)
- 위치를 고르기 전에는 비워 둔다. '위치 고르기'를 누르면 현재 위치 찾기나 시도·시군구를 고르고, 고른 곳은 이 브라우저에 저장한다.
  고르기 전 오늘의 기름 소식은 전국 평균만 보인다.
- 개인정보 처리방침은 페이지(/privacy)만 만들고 화면 아래와 내 정보 화면에서 링크한다.
- 카카오 로그인(진짜 계정)은 별도 작업으로 한다(이 설계 밖).

## 방법(빌더의 판단)
- 고른 위치는 지금의 내 정보 저장소(profile.area, profile.location)에 이름 없이 저장한다. 로그인 상태(이름 있음)는 바뀌지 않는다.
- 조건 줄의 출발 위치: 위치·지역이 없으면 '위치 고르기' 버튼. 누르면 작은 창(휴대폰은 아래 시트)에 현재 위치로 찾기 + 시도→시군구.
  고른 뒤에는 지금 메뉴(내 위치 + 그 시도의 시군구청) 끝에 '다른 지역 고르기…'.
  - 230곳을 한 메뉴에 몰아넣는 방법은 휴대폰에서 너무 길어 버렸다. 내 정보 화면과 같은 두 단계로 고른다.
- 울주군을 대신 쓰던 곳은 고른 위치를 따른다. 고르기 전에는:
  - 오늘의 기름 소식: 전국 평균만.
  - 출발 위치가 필요한 상자(근처 최저가, 거리까지 고려한 추천, 요소수 재고, 고속도로 휴게소)와 지역이 필요한 상자(알뜰주유소, 제일 싼 곳 질문): 누르면 위치 고르기 창을 먼저 연다.
  - 알림 기본 지역, 월간 리포트의 시도 평균 비교: 고른 지역, 없으면 비워 둔다(비교는 생략).
  - 챗봇: 지역을 말하지 않았고 고른 위치도 없으면 울주군으로 정하지 않고 어느 지역인지 묻는다.
    로그인 전에도 고른 지역·위치는 질문과 함께 보낸다(이름은 보내지 않는다).
- 그대로 두는 것: 고정 질문 '지난 고시 뒤 우리 동네는?'은 울주군으로 미리 셈한 자료라 울주군 예시로 남긴다.

## 개인정보 처리방침(/privacy)
처리하는 정보와 목적, 보관 장소·기간(대부분 이 브라우저에만, 서버는 저장하지 않음), 답을 만들려고 보내는 곳
(Anthropic Claude API, 미국), 호스팅(Vercel, 미국), 국외 이전 항목, 제3자 제공 없음, 지우는 방법, 문의처, 시행일.
실제로 서버가 무엇을 남기는지(호출 제한용 접속 정보, Vercel 로그)는 만들 때 코드로 확인해 적는다.
운영 주체 이름과 문의 연락처는 팀이 정해 준다. 법률 검토는 아니다.
